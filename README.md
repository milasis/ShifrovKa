# ShifrovKa

**ShifrovKa** — это учебное клиент-серверное приложение с графическим интерфейсом, реализующее защищённую передачу сообщений по сети с использованием симметричного шифрования AES (режим CBC).

## 🧩 Особенности

- 🖥️ Два отдельных интерфейса: клиент и сервер
- 🔐 Алгоритм шифрования: AES (CBC, 128 бит, IV)
- 🧾 Поддержка команд ENCRYPT и DECRYPT
- 💬 Передача сообщений по TCP (localhost)
- 🎨 Минималистичный светлый интерфейс без эмодзи
- 📦 Упаковка в `.exe` с помощью `pyinstaller`
